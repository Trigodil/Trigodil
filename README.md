### What I work on

- **Aerospace research** - Su-57 aerodynamics via NASA DATCOM, engine thermal failure analysis in fighter aircraft ([IDRW](https://idrw.org/research-flags-inlet-design-constraints-in-tejas-mk1-after-dubai-incident/))
- **Systems & robotics** - [Project Flockwork](https://github.com/Trigodil/Project-Flockwork): decentralized drone swarm control in C++ on ROS 2 + Gazebo.
- **Compilers** - working on contributing to Rust and Clang, and improving memory safety in C++.
- **Security** - HackerOne bug bounty, VDP findings, kernel security research
- **CFD** - [CakeCFD](https://cakecfd.org): open source CFD platform built on OpenFOAM with high-order TENO schemes, a native desktop app, and an AI interface that runs simulations from natural language
- **Tools** - [jan-terminal-mcp](https://github.com/Trigodil/jan-terminal-mcp): Gave terminal access to Jan
